# MiniRoyalePython

Protótipo 2D inspirado em jogos de arena com cartas, feito em Python + Pygame.

## Rodar
```bash
pip install -r requirements.txt
python src/main.py
```

## Controles
- Clique na carta Cavaleiro.
- Clique na metade inferior da arena para invocar.
- A tropa anda e ataca automaticamente.
- Pressione R para reiniciar após vencer.
